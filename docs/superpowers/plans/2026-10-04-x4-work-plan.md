# X4 Work-screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Work browse open PRs and the latest default-branch build for public acgh213/alicenet-x4, with honest freshness and failure states.

**Architecture:** A bounded GET-only collector writes a separate atomic Work snapshot. Existing gateway frame identity and per-device navigation render it; a separate configured refresh command keeps Work failures independent of HA sources.

**Tech Stack:** Python 3.11+, stdlib urllib/json/pathlib/unittest, existing Pillow renderer and SQLite gateway; existing systemd user-service pattern. No new product dependencies.

## Review Focus
1. Renamed/private repository or changed default branch: never retain former source data or present old-branch CI as current.
2. Removed/reordered PR between drawing and Confirm: open the displayed identity or give a changed-item notice; never open a different cursor item.
3. Structurally valid but misleading provider data (future timestamps, wrong branch, successful run for older head): reject invalid observations or show explicit limits.
4. Missing/corrupt config or snapshot and process interruption: renderer stays usable; partial writes never replace a valid snapshot.
5. Refresh lock contention or nonzero collector exit after writing failure state: avoid parallel collection and still redraw honest failure state.
